# meeting-action-agent
# AI-Powered Meeting Intelligence & Task Management System

## 🚀 About the Project

An AI-powered application that converts conversations and meeting discussions into meaningful insights, decisions, commitments, and actionable tasks.

The system uses Large Language Models (LLMs) to analyze meeting content, identify responsibilities, assign task owners, determine priorities, and track deadlines.

## ✨ Key Features

- **AI-Powered Analysis:** Automatically analyzes meeting transcripts and conversations.
- **Decision Extraction:** Identifies important decisions made during discussions.
- **Action Item Detection:** Converts conversations into actionable tasks.
- **Smart Task Assignment:** Identifies task owners and responsibilities.
- **Deadline Detection:** Extracts deadlines and due dates.
- **Priority Management:** Categorizes tasks based on urgency.
- **Centralized Dashboard:** Displays tasks, decisions, and commitments in one place.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript / React
- **Backend:** Node.js / Express.js
- **Database:** Supabase
- **AI Integration:** LLM API
- **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

1. Clone the repository:

   `git clone YOUR_REPOSITORY_URL`

2. Navigate to the project directory:

   `cd project`

3. Install dependencies:

   `npm install`

4. Configure your environment variables in `.env`.

5. Start the application:

   `npm run dev`
